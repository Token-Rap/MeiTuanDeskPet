# MeiTuanDeskPet v0.1.0

First public desktop build of MeiTuanDeskPet, a Flutter-powered transparent desktop pet with a generated photorealistic white cat.

## Highlights

- Adds the realistic white cat desktop pet with transparent, always-on-top window behavior.
- Adds quiet sleeping idle behavior with a curled sleeping pose and infrequent sleep motion.
- Adds click-to-greet animation, direction-aware dragging, and smoother frame interpolation.
- Adds a custom cute app icon.

## Downloads

- **macOS**: download the `.dmg` installer. The `.zip` is also provided for users who prefer a portable app bundle.
- **Windows**: download the `windows-x64-setup.exe` installer. The `.zip` is also provided as a portable package.
- **Linux**: download the `.deb` package for Debian/Ubuntu-based systems, or the `.tar.gz` portable bundle.

## Notes

- macOS and Windows packages are currently unsigned. Your OS may show a first-run warning.
- Linux desktop integration is included in the `.deb` package; the `.tar.gz` bundle can be run directly from its extracted folder.
