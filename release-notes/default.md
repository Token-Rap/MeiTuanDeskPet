# MeiTuanDeskPet Release

This release provides packaged desktop builds for macOS, Windows, and Linux.

## Downloads

- **macOS**: `.dmg` installer and `.zip` app bundle.
- **Windows**: `.exe` installer and `.zip` portable package.
- **Linux**: `.deb` package and `.tar.gz` portable bundle.

## Notes

- macOS and Windows packages are currently unsigned. Your OS may show a first-run warning.
- Linux desktop integration is included in the `.deb` package.
