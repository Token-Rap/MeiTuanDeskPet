# Windows 双猫预览

- 小团和小美使用新的实拍参考形象，包含摸摸、行走和睡眠动作。
- 小团体型更厚实，显示尺寸比小美大约 13%。
- 左键摸摸，拖动移动，右键切换小团和小美。

Windows x64：下载 setup.exe 安装，或下载 preview.zip 后完整解压，运行 meituan_desk_pet.exe。
这是供实际效果检查的预览版本；安装包未签名，尚未完成真人 Windows 视觉验收。

拖动修复：按素材实际比例绘制，统一脚底基线，四周增加留白；Windows 原生拖动取消 Flutter 手势时保持行走姿势，松手后再恢复。

待机睡姿更新：小团按实拍蜷睡，小美按实拍侧躺伸展；安静待机与25分钟一次轻微呼吸动作使用同一睡姿素材。

方向修复：Windows 原生拖动按窗口实际移动增量更新朝向，同一次拖动中反向无需越过起点；过滤轻微抖动。

系统托盘与更新：
- 双猫专用图标，替换 Flutter 默认图标。
- 托盘显示/隐藏、切换猫咪、手动检查并安装更新、自动更新开关、退出。
- 默认在启动15秒后及每4小时检查 GitHub Release。发现新版后通知、下载、SHA-256校验，再运行安装器并重启应用。
- 更新安装仍遵循 Windows 管理员授权；拒绝或安装失败后可重试。
- 预览版跟随预览及正式发布；正式版只跟随正式发布。旧版没有更新功能，需要先手动安装本版。

图标与尺寸：运行中主窗口、Flutter子窗口及快捷方式显式使用双猫图标；两只猫及交互窗口缩小约20%，保留小团较大的体型。

小团睡眠与点击动作重制：分别采用5张真实照片，保留浅灰额纹、实际脸型、厚实躯干。睡眠改为低趴，点击保持趴姿并眯眼抬头，按各帧透明轮廓对齐。
